## 🎯 今日任务

显示今日待办文件中尚未完成的任务。
```tasks-fold
not done
path includes {{today.file}}
description regex does not match /^\s*$/
sort by priority
```

## 📥 待办任务
按每日笔记的日期分组，点击日期可打开对应笔记。包含所有未完成且未逾期的任务，不限制日期范围；往日没有截止日期的任务也会保留。
```tasks-fold
not done
path regex matches /^To do\/\d{4}-\d{2}-\d{2}\.md$/
description regex does not match /^\s*$/
(no due date) OR (due on or after today)
group by filename
sort by filename
sort by due
```

## 🔥 今日到期任务
显示明确设置了 📅 截止日期、今天到期且尚未到截止时间的未完成任务。已到截止时间的任务进入逾期分区。
```tasks-fold
not done
path regex matches /^To do\/\d{4}-\d{2}-\d{2}\.md$/
description regex does not match /^\s*$/
due on today
sort by priority
```

## ⚠️ 逾期任务
显示已到截止时间的未完成任务，包括今天已到 🕒 时刻的任务；只写日期时，到次日才算逾期。没有截止日期的旧任务继续留在待办中。
```tasks-fold
not done
path regex matches /^To do\/\d{4}-\d{2}-\d{2}\.md$/
description regex does not match /^\s*$/
due before today
sort by filename
sort by due
```
