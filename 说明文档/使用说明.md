# 每日待办使用说明
[[总览/任务总览|打开任务总览]] · [打开 / 创建本周总览](obsidian://daily-todo-views?vault=%E6%AF%8F%E6%97%A5%E5%BE%85%E5%8A%9E&view=week) · [[搭建说明|安装与配置]]

本文按日常使用的重要性排序，覆盖每日笔记、截止日期与时间、任务总览、统计日历、周总览、任务整理和模板维护，并补充已安装 Tasks 的常用进阶操作。新手先看前四节，其余按需要查阅。

## 一、每天先这样用
1. 打开 [[总览/任务总览|任务总览]]，先看“逾期任务”和“今日到期任务”，确认哪些事情需要优先处理。
2. 点击“打开 / 创建今日待办”，填写“今日最重要的三件事”，其他任务放进学习、工作或生活分类。
3. 有期限的任务设置截止日期，需要精确到分钟时再设置时间。
4. 做完一项就勾选一项；晚上在每日笔记的“今日记录 / 今日总结”写下进展和遗留事项。

未完成任务会继续出现在相应总览中，不必每天复制。每件事只记录一次，同一任务出现在不同视图中仍是同一条记录。

## 二、创建、填写和修改每日任务
### 1. 打开今天、过去或未来的笔记

| 想做什么 | 怎么操作 | 结果 |
| --- | --- | --- |
| 安排今天 | 在任务总览点击“打开 / 创建今日待办” | 打开今天的笔记；没有时按每日模板创建 |
| 提前安排明天 | 点击 Obsidian 左侧竖向工具栏中的“日历加号”按钮，悬停提示为“创建明日待办” | 从明天起逐日查找，跳过已有日记，按每日模板创建并打开第一个尚无日记的日期 |
| 补记过去或安排未来 | 在任务总览底部日历翻到目标日期，点击日期数字 | 打开或创建对应日期的笔记 |
| 找已有笔记 | 在左侧文件列表打开 `To do` 中对应日期的文件 | 直接编辑当天内容 |

每日笔记保存在 `To do/YYYY-MM-DD.md`。例如 `To do/2026-10-18.md` 中的任务属于 10 月 18 日的安排；所属日期与截止日期可以不同。

“创建明日待办”每次都从当前日期的明天开始查找。例如今天是 10 月 18 日，19 日和 20 日已有日记时，会创建 21 日的日记；如果只有 20 日已有日记，仍会先创建 19 日。已有日记不会被覆盖，需要修改时从日历或文件列表打开。

### 2. 添加任务和分类
在编辑模式下，每行输入一项任务，使用下面的格式；`[ ]` 中间留一个空格：
```markdown
- [ ] 复习集合框架
- [ ] 提交实验报告 📅 2026-10-21
- [ ] 参加线上会议 📅 2026-10-21 🕒 18:30
```

“今日最重要的三件事”直接写最重要的任务，学习、工作、生活分类只补充其他事项。分类标题可以按需调整，不影响按笔记日期汇总。模板中的空白 `- [ ]` 是占位，填写内容后才会被总览和日历计入；不用的占位可以删除。

### 3. 修改内容和拆分步骤
在每日笔记中直接修改任务文字。任务太大时，可另起几行拆成步骤；需要层级时，将步骤缩进到父任务下面：
```markdown
- [ ] 完成实验报告
  - [ ] 整理数据
  - [ ] 撰写结论
```

父任务和子任务各有自己的完成状态，需要分别勾选；日历也会分别计数。普通说明、思路和过程记录写成正文即可，只有任务行参与任务统计。

## 三、设置截止日期与时间
### 1. 用弹窗设置或修改
1. 打开任务所在的每日笔记，切到编辑模式，将光标放在要设置的任务行。
2. 右键选择“设置截止日期与时间”；也可按 `Ctrl+P` 打开命令面板，搜索并执行同名命令。
3. 选择截止日期。需要具体时间时，分别选择小时和分钟，或在“手动输入时间”填入 `18:30`。
4. 点击“保存”。任务行会写入或更新为 `📅 YYYY-MM-DD 🕒 HH:mm`，时间位于日期后面。

时间采用 24 小时制，例如上午八点半写 `08:30`。已有日期和时间会回填到弹窗，再次打开即可调整；只选小时或只选分钟时需要补全，或清除时间。点击“取消”放弃本次修改。

### 2. 只设置日期、清除时间或取消期限

| 需要 | 怎么操作 |
| --- | --- |
| 只限制到某一天 | 选择日期，时间留空后保存 |
| 清除已有时间 | 在弹窗点击“清除时间”，再点击“保存”；原截止日期保留 |
| 取消整个截止期限 | 在原任务行删除 `📅 日期` 和 `🕒 时间` 两部分 |
| 手动填写 | 在任务内容后写 `📅 2026-10-21`，需要时间再接 `🕒 18:30` |

设置精确时间时必须同时写截止日期；单独的 `🕒 18:30` 不会形成截止期限。

### 3. 什么时候算逾期

| 写法 | 判断方式 |
| --- | --- |
| 没有截止日期 | 不会因笔记日期过去而自动逾期 |
| `📅 2026-10-21` | 10 月 21 日全天有效，10 月 22 日起算逾期 |
| `📅 2026-10-21 🕒 18:30` | 10 月 21 日到 18:30 时算逾期 |

已到截止时间且未完成的任务会移出“待办任务”“今日到期任务”和“即将截止”统计，进入“逾期任务”。如果它写在今天的笔记里，仍会出现在“今日任务”中，方便继续处理。

判断使用设备本地日期和时间。相关视图按分钟检查，跨零点也会更新；刚到截止时刻时，允许等待下一次分钟刷新。这里的截止功能用于列表归类和统计，没有单独的系统通知或响铃入口。

### 4. 查看每日笔记的“当天即将截止”
打开每日笔记中的“当天即将截止”，切到阅读视图即可查看。它跨所有每日笔记汇总，在这篇笔记日期到期、未完成且尚未到截止时间的任务，能带出以前记录的事项；也可直接在列表中勾选完成。

这里的“当天”取自笔记文件名。打开 10 月 21 日的笔记，查看的是 10 月 21 日到期的任务。查看过去日期时，该区为空；查看今天时，已到具体截止时间的任务会被排除，转到全局总览的“逾期任务”处理。该列表同样支持超过 5 条后展开、收起。

## 四、完成、恢复、延期和删除任务

| 操作 | 怎么使用 | 会发生什么 |
| --- | --- | --- |
| 完成任务 | 在每日笔记或总览中点击任务复选框 | 原笔记同步变为完成；启用 Tasks 完成日期记录后会添加 `✅ YYYY-MM-DD` |
| 恢复误勾的任务 | 再点击一次已完成任务的复选框 | 恢复未完成，按期限重新出现在对应分区 |
| 用命令切换完成状态 | 编辑模式下将光标放到任务行，按 `Ctrl+P`，执行 `Tasks: Toggle task done` | 切换当前任务的完成状态 |
| 延后截止期限 | 在原任务行重新打开截止弹窗，改日期或时间后保存 | 更新期限，任务所属笔记日期不变 |
| 改到另一天安排 | 剪切整条任务，粘贴到目标日期的每日笔记 | 所属日期、周范围和日历计数随新笔记改变；截止日期需按需要另行修改 |
| 删除不再需要的任务 | 在原笔记中删除整条任务行 | 任务从总览和统计中移除 |

删除任务会丢失这条记录；希望保留完成历史时使用勾选。总览中的任务是原笔记的查询结果，修改文字、调整安排或删除时，先点击来源链接回到原笔记。

## 五、查看任务总览，找到当前要做的事
### 1. 五个分区分别看什么
打开 [[总览/任务总览|任务总览]]，切到阅读视图查看任务列表。遇到多种待办时，建议先处理逾期和今日到期，再看今天的安排及其他待办。

| 分区 | 显示内容 | 常见用途 |
| --- | --- | --- |
| 逾期任务 | 截止日期已过去，或今天已到截止时间，仍未完成的任务 | 补做、调整期限或删除失效事项 |
| 今日到期任务 | 今天截止、未完成且尚未到截止时间的任务；仅写今天日期的任务也会列入 | 确认今天必须交付的事情 |
| 今日任务 | 今天每日笔记中所有未完成任务，包括已逾期任务 | 按今天的安排执行 |
| 待办任务 | 所有每日笔记中未完成且未逾期的任务，包括往日无期限和未来的任务 | 检查长期积压和后续安排 |
| 今日完成 | 完成日期 `✅` 记录为今天的任务，无论最初写在哪一天 | 回顾今天完成了什么 |

分区有重叠，同一任务可能同时出现在“今日任务”“待办任务”“今日到期任务”。这些是不同角度的汇总，不是重复创建的任务。

### 2. 展开、收起和跳回原文
每个任务分区默认最多显示 5 条，底部显示“共 N 条”。超过 5 条时点击“展开全部”，看完点击“收起至 5 条”。每个分区独立展开。

点击分组日期或任务旁的来源链接可打开原每日笔记。总览会随 Tasks 索引更新；编辑模式看到查询代码时，切回阅读视图查看结果。

## 六、使用月历和周历安排日期
### 1. 切换范围与打开笔记
在 [[总览/任务总览|任务总览]] 底部使用日历工具栏：

| 按钮或位置 | 用法 |
| --- | --- |
| 月历 / 周历 | 切换整月网格和周一至周日的视图 |
| 上一月 / 下一月 | 在月历模式切换月份 |
| 上一周 / 下一周 | 在周历模式切换周 |
| 本日 | 回到包含今天的月份或周 |
| 日期数字 | 打开当天笔记，没有时按模板创建 |
| 更新于 | 查看当前统计的最近刷新时间 |

今天的日期会突出显示，月历中的相邻月份日期会弱化显示。点击未来日期就能提前安排任务，点击过去日期可以补记或查看历史。

### 2. 三个数字如何理解

| 统计 | 按什么日期归类 | 包含什么 |
| --- | --- | --- |
| 待完成 | 任务所在每日笔记的日期 | 这篇笔记中未完成的任务，包含已逾期的任务 |
| 已完成 | 任务所在每日笔记的日期 | 这篇笔记中已完成的任务，不要求在当天完成 |
| 即将截止 | 任务的 `📅` 截止日期 | 所有每日笔记中该日到期、未完成且尚未到截止时间的任务 |

例如，10 月 18 日的笔记里写了任务，截止日期设为 10 月 21 日。未完成时，它计入 10 月 18 日的“待完成”和 10 月 21 日的“即将截止”；完成后计入 10 月 18 日的“已完成”。总览“今日完成”则按实际记录的完成日期判断。

“即将截止”只在今天及未来日期显示，跨所有每日笔记统计；过去日期不显示这项。三个数字采用不同口径，不要相加当作任务总数。勾选或修改后会自动更新，Tasks 首次加载索引时可能暂时显示 `—` 或加载提示。

## 七、使用周总览回顾和安排一周
### 1. 打开本周或其他周
点击页面上的“打开 / 创建本周总览”，或按 `Ctrl+P` 执行“每日待办视图：打开 / 创建本周总览”。文件保存在 `总览/周任务总览/`，以周一日期命名，例如 `2026-10-12 周总览.md` 对应 10 月 12 日至 18 日。

查看其他周时，从该文件夹打开对应文件。需要生成某一周时，在全局总览日历中打开该周任意一天的每日笔记，插件会补建对应周文件，再到文件夹打开。

### 2. 自动创建与已有文件
打开库时会检查本周；进入新的一周后会自动补建新周文件；新建或打开某天的每日笔记时，也会检查那天所属周。已有周文件会保留，不会被重新生成的内容覆盖。

### 3. 周总览和全局总览的区别
周总览也有五个任务分区，但任务来源只限该周七天的每日笔记。任务按写在哪一周归属，不按截止日期归属。其他周记录、本周到期的任务，需要从全局总览的到期分区查看。

周文件的来源范围固定，之后打开仍是同一周；其中“今日任务、今日到期、逾期、今日完成”按打开时的当前日期判断，因此它不是当周结束时的状态快照。查看历史周时，“今日任务”可能为空。

周总览底部的日历固定显示那一周，没有月份切换和前后翻页按钮，点击日期仍可打开或创建每日笔记。其中“即将截止”仍跨所有每日笔记统计，能包含其他周记录的任务。

## 八、按需要使用任务进阶功能
以下是已安装 Tasks 和 Obsidian 提供的常用操作，不需要改总览查询。

### 1. 设置优先级
在任务内容后添加优先级标记；不写标记时为普通优先级：

| 从高到低 | 标记 |
| --- | --- |
| 最高 | `🔺` |
| 高 | `⏫` |
| 中 | `🔼` |
| 普通 | 不写标记 |
| 低 | `🔽` |
| 最低 | `⏬` |

例如 `- [ ] 提交实验报告 ⏫ 📅 2026-10-21`。包含“按优先级排序”的视图会优先显示较高优先级；当前“今日任务”“今日到期任务”和每日笔记“当天即将截止”使用这一排序。“今日最重要的三件事”是手动规划区域，不会自动给任务加优先级。

### 2. 创建重复任务
对于背单词、周报等周期事项，在任务中添加重复规则和截止日期：
```markdown
- [ ] 背单词 🔁 every day 📅 2026-10-18
- [ ] 写周报 🔁 every week 📅 2026-10-23
- [ ] 整理资料 🔁 every month 📅 2026-10-31
```

完成时点击每日笔记或总览中的复选框，或执行 `Tasks: Toggle task done` 命令，Tasks 会保留本次完成记录并生成下一次任务。新任务仍写在原笔记中，不会自动搬到下一天的笔记，因此之后可在全局“待办任务”及到期分区找到它；希望出现在新一天的“今日任务”时，再将新任务移到对应每日笔记。

重复规则使用上述英文写法；要从实际完成日推算下一次，可使用 `🔁 every day when done`。已有精确时间时，完成后检查新任务的截止日期和 `🕒` 时间是否符合安排。

### 3. 用 Tasks 弹窗编辑其他属性
编辑模式下将光标放在任务行，按 `Ctrl+P`，执行 `Tasks: Create or edit task`，可通过 Tasks 自带编辑器调整内容、优先级、重复规则和日期。精确到分钟的截止时间使用第三节的“设置截止日期与时间”。

Tasks 还支持开始日期 `🛫 YYYY-MM-DD`、计划日期 `⏳ YYYY-MM-DD` 和创建日期 `➕ YYYY-MM-DD`；需要时在编辑器中设置或直接填写。本项目的“今日任务”和日历“待完成 / 已完成”始终按每日笔记日期归类，填写这些属性不会改变归属；截止判断使用 `📅`。

### 4. 添加标签、关联笔记和查找任务
任务末尾可以加 `#学习`、`#工作` 等标签，也能用 `[[笔记名称]]` 关联资料。例如 `- [ ] 复习集合框架 #学习 [[Java笔记]]`；点击内部链接可打开相关笔记。

查找时按 `Ctrl+Shift+F` 打开库搜索，输入关键词或标签；也可按 `Ctrl+P` 执行 `Tasks: Quick search` 查找任务。搜索库内文字时可能同时找到说明和模板，确认文件位于 `To do` 后再修改实际任务。

## 九、记录总结和整理历史
在每日笔记的“今日记录 / 今日总结”填写完成情况、卡点和下一步。这里的普通文字不参与任务统计；需要继续追踪的事项再写成任务行。

旧任务可以留在原笔记，未完成且无期限的任务会持续留在全局待办中；已逾期任务在逾期分区查找。历史每日笔记可通过左侧文件列表或全局日历打开；历史周总览从 `总览/周任务总览/` 打开。保留历史任务时，维持 `To do/YYYY-MM-DD.md` 路径，移到其他目录后将不再参与按此路径限定的汇总和日历统计。

## 十、调整模板、快捷键和检查插件
### 1. 修改以后新建的页面

| 想调整什么 | 打开什么 | 怎么改 |
| --- | --- | --- |
| 每日分类、默认任务、总结栏目 | [[Templates/Daily-Template\|每日模板]] | 修改标题、正文或任务，新建每日笔记时采用 |
| 新周总览的栏目和说明 | [[Templates/Weekly-Template\|周模板]] | 修改模板，新建周文件时采用 |
| 全局总览的说明、导航和分区位置 | [[总览/任务总览\|任务总览]] | 在原文件中编辑或移动对应的整块内容 |

修改模板不会自动更新已有笔记；需要时单独修改旧文件。日期占位符和查询代码负责自动取日期、筛选任务，保留原样。手动创建每日笔记时，可用核心“模板”插件插入每日模板；需要创建其他日期时优先从日历入口操作，日期会按目标日填写。

### 2. 设置常用命令快捷键
打开“设置 → 快捷键”，搜索“设置截止日期与时间”“打开 / 创建本周总览”或 `Tasks: Toggle task done`，为常用操作绑定自己顺手的按键。没有绑定时统一通过 `Ctrl+P` 命令面板调用；任务编辑命令需要光标位于任务行。

### 3. 检查插件和完成日期
打开“设置 → 第三方插件”，确认 Tasks 和“每日待办视图”均启用。在“设置 → 每日待办视图”查看插件版本、Tasks 统计读取状态及日期时间兼容提示；该页面主要用于确认运行状态。

在 Tasks 设置中，将全局过滤器（Global filter）保持为空，并启用“Set done date on every completed task”。前者让普通任务参与识别，后者为“今日完成”记录完成日期。该设置不会为以前已经完成但没有日期的任务补写历史日期。

首次安装、重新配置、迁移备份、修改折叠条数或插件代码时，按 [[搭建说明]] 操作。备份或迁移整套库时包含 `.obsidian`，以保留插件和配置。

## 十一、遇到问题时按这里检查

| 现象 | 简单处理 |
| --- | --- |
| 总览只显示 `tasks-fold`、`todo-calendar` 代码 | 先切到阅读视图；仍未渲染时确认“每日待办视图”已启用，更新插件文件后完整退出再打开 Obsidian |
| 日历显示 `—` 或“索引加载中” | 等待 Tasks 索引完成；持续不更新时检查 Tasks 是否启用，以及设置页的统计读取状态 |
| 写了任务却没出现在总览或统计中 | 检查是否写在 `To do/YYYY-MM-DD.md`、是否为有内容的 `- [ ]` 任务，并确认全局过滤器为空；再检查所看的分区或周范围 |
| 昨天没完成的任务不在“今日任务” | “今日任务”只查今天的笔记，去“待办任务”或“逾期任务”找；需要今天重新安排时将原任务移到今天 |
| 勾选后“今日完成”没有记录 | 检查原任务是否带今天的 `✅ YYYY-MM-DD`，并确认 Tasks 的完成日期设置已启用；周总览还要求来源笔记属于那一周 |
| 截止时间没有生效 | 同时填写 `📅 YYYY-MM-DD` 和 `🕒 HH:mm`，使用 24 小时制，确认设备时间，并等待下一次分钟刷新 |
| 右键没有截止日期命令 | 打开原笔记，进入编辑模式，把光标放到任务行，再右键；也可从命令面板执行 |
| 弹窗提示“任务已被修改” | 关闭弹窗，重新定位任务行后再打开设置 |
| 本周总览没有生成 | 执行“打开 / 创建本周总览”，确认 [[Templates/Weekly-Template\|周模板]] 存在；打开其他周的每日笔记可补建对应周文件 |
| 改了模板，旧笔记没变化 | 模板只影响新建文件，已有文件需要手动修改 |
| “打开 / 创建今日待办”失败或打开了别的库 | 按 [[搭建说明]] 核对核心“日记”的目录和模板配置；库改名后同步更新链接中的 `vault` 参数 |
| 日历数量与“今日完成”数量不同 | 日历完成数按任务所在笔记日期统计，“今日完成”按 `✅` 完成日期统计；父子任务也分别计数 |
