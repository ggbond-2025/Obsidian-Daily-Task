# 每日待办搭建说明
适用于 Windows 上从零搭建这套笔记库，或把现有库迁移到其他电脑。日常使用需要 Obsidian、Tasks 和项目提供的本地“每日待办视图”插件；不需要安装 Node.js。

[[使用说明|日常使用说明]] · [[总览/任务总览|打开任务总览]]

> [!tip] 已经使用本项目
> 现有库已经包含相关文件和配置，不必重复搭建。插件文件更新后，完整退出再打开 Obsidian，确认 Tasks 和“每日待办视图”已启用。首次安装和文件迁移再按下文逐步操作。

## 一、从零搭建
### 1. 安装 Obsidian，打开或创建库
从 [Obsidian 官网](https://obsidian.md/download) 下载并安装 Windows 版本。项目内 Tasks 8.6.0 要求 Obsidian 至少为 1.13.1。

使用整套项目时，在库管理界面选择“打开文件夹为库”，选择 `C:\Users\ggbond\Desktop\每日待办`，直接使用已有笔记和配置。

重新搭建时，选择“创建新库”，库名使用 `每日待办`，再完成后续配置并复制项目文件。当前按钮链接中写有这个库名；库改名后，也需要更新模板和已有笔记中 `obsidian://` 链接的 `vault` 参数。
### 2. 准备目录和项目文件
最终目录结构如下；日期文件是使用时生成的示例，重新搭建时不用预先创建：
```text
每日待办/
├─ 搭建说明.md
├─ 使用说明.md
├─ To do/
│  └─ 2026-10-18.md
├─ Templates/
│  ├─ Daily-Template.md
│  └─ Weekly-Template.md
├─ 总览/
│  ├─ 任务总览.md
│  └─ 周任务总览/
│     └─ 2026-10-12 周总览.md
└─ .obsidian/
   └─ plugins/
      ├─ obsidian-tasks-plugin/
      └─ daily-todo-views/
         ├─ manifest.json
         ├─ main.js
         └─ styles.css
```

新库先建立 `To do`、`Templates` 和 `总览`，再复制本项目的两份模板、`总览/任务总览.md`、根目录的 `搭建说明.md`、`使用说明.md` 到对应位置。`总览/周任务总览` 会在第一次生成周总览时自动建立，也可以提前手动建立。

文件夹名称和每日文件的 `YYYY-MM-DD.md` 格式参与查询和自动创建，请保留上述名称。这里只需复制项目提供的文件，不需要从头编写插件代码。
### 3. 配置核心插件“日记”和“模板”
在“设置 → 核心插件”启用“日记”和“模板”，然后在“设置 → 日记”填写以下内容：

| 设置项 | 值 |
| --- | --- |
| 日期格式 | `YYYY-MM-DD` |
| 新建日记的存放位置 | `To do` |
| 模板文件位置 | `Templates/Daily-Template.md` |

在“设置 → 模板”将模板文件夹位置设为 `Templates`。核心日记插件负责“打开 / 创建今日待办”链接，新文件会套用每日模板。官方说明见 [日记](https://obsidian.md/help/plugins/daily-notes) 和 [模板](https://obsidian.md/help/plugins/templates)。
### 4. 安装并启用 Tasks
进入“设置 → 第三方插件”，按界面提示启用第三方插件功能，打开社区插件浏览，搜索 `Tasks`，安装后再点击启用。参见 [Obsidian 第三方插件说明](https://obsidian.md/help/Extending+Obsidian/Community+plugins)。

在 Tasks 设置中，将全局过滤器（Global filter）保持为空，使普通 `- [ ]` 任务也能被识别；启用“Set done date on every completed task”（每次完成时设置完成日期），供“今日完成”查询使用。日期格式使用默认的 Tasks Emoji 格式，例如 `📅 2026-10-21`。

本项目已适配随项目安装的 Tasks 8.6.0。总览没有使用 JavaScript 自定义查询，不需要打开“Enable custom searches”。
### 5. 安装本地“每日待办视图”
这是本项目自带的本地插件，社区插件市场中不一定能搜索到。在 Windows 文件资源管理器中进入新库，将项目的以下三个文件复制到相同位置；没有对应文件夹时先建立：
```text
.obsidian/plugins/daily-todo-views/manifest.json
.obsidian/plugins/daily-todo-views/main.js
.obsidian/plugins/daily-todo-views/styles.css
```

`.obsidian` 是库配置目录；如果看不到，可以在文件资源管理器地址栏直接输入完整路径进入。

完整退出并重新打开 Obsidian，在“设置 → 第三方插件 → 已安装插件”中启用“每日待办视图”。设置左侧应出现同名页面，显示版本 `1.5.0` 和 Tasks 读取状态。无需额外参数，也不用另装日历插件。该版本提供截止日期时间弹窗，并适配 `📅 YYYY-MM-DD 🕒 HH:mm` 的顺序，操作见 [[使用说明]]。
### 6. 检查是否可用
打开 [[总览/任务总览|任务总览]] 并切到阅读视图，应看到五个任务分区和底部日历。点击“打开 / 创建今日待办”，应在 `To do` 中打开当天文件并套用每日模板。

插件加载后会检查本周文件。例如 2026-10-18 对应 `总览/周任务总览/2026-10-12 周总览.md`。无任务时列表为空是正常的；原样显示 `tasks-fold` 或 `todo-calendar` 代码块则需要检查插件加载。

## 二、模板与插件维护

| 想调整的内容 | 维护位置 |
| --- | --- |
| 每日分类和查询 | [[Templates/Daily-Template\|Daily-Template 每日模板]] |
| 新周总览的内容 | [[Templates/Weekly-Template\|Weekly-Template 周模板]] |
| 全局分区与导航 | [[总览/任务总览\|任务总览]] |
| 安装配置与维护步骤 | 根目录的 [[搭建说明]] |
| 日常使用与规则 | 根目录的 [[使用说明]] |
| 折叠条数 | `.obsidian/plugins/daily-todo-views/main.source.js` 顶部 `PREVIEW_LIMIT` |
| 日期和自动创建逻辑 | 同一插件目录的 `core.js`、`main.source.js` |
| 日历与列表样式 | 同一插件目录的 `styles.css` |

改模板和普通笔记不需要构建。只有修改插件 JavaScript 源码时才需要 Node.js，以及项目提供的 `core.js`、`main.source.js` 和 `build.cjs`（仅复制三个运行文件的库不含这些维护文件）。在库根目录 PowerShell 中运行以下命令，再重新加载插件或重启 Obsidian：
```powershell
node .obsidian/plugins/daily-todo-views/build.cjs
```

`main.js` 是生成的运行入口，应修改源文件后构建；修改 CSS 后重新加载插件即可。本地插件复用 Tasks 查询、索引和勾选回写，无需额外联网服务。

复制整个笔记库到其他电脑时，请包含 `.obsidian` 文件夹，并在目标设备确认两个第三方插件已启用。本地插件没有发布到社区市场，不会通过社区市场自动更新。

本文已静态核对目录、配置、安装文件及构建命令；未进行一次全新安装验收。日常任务规则见 [[使用说明]]。
